# Medication Calculator

A simple medication dosage calculator built with React, Vite, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Every push and pull request runs the production build. Pushes to `main` also publish the build to GitHub Pages. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
